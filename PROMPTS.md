# Messages to send Claude Code

Open Claude Code in this folder, then paste these one at a time. Change the words in quotes to your own.

## Pick the moments

```
Here is my clip: clip.mov. Make a contact sheet of it every half second and tell me
the best 3-second moments for each look: one where I point up, one where I smile at
the camera, one where I talk with my hands.
```

## Render one look

```
Extract 2.6 seconds from clip.mov starting at 4.5 seconds, with the cut-out.
Render the behind look with the words "Built in" and "1 day" in my shirt colour.
Show me a still from the middle before you render the full video.
```

## Change a look

```
In the glass look, change the views number to 48K and the label to "Saves".
Move every widget so nothing covers my face.
```

```
Make the orbit look use my own covers. They are in covers/: copy them to looks/cards/1.jpg ... 8.jpg.
```

## Build a full reel

```
Make a 20-second reel from clip.mov: 6 looks, about 3 seconds each, each on a different
moment of the clip. Render each look, join them with stitch.sh, and show me a contact sheet
of the result before you call it done.
```

## Make it premium

These are real notes I gave Claude while editing my own reels:

- "Text is on my head. Move it." (cards belong at chest level)
- "Such a poor image. Use the highest quality." (only sharp, official images)
- "Show me a still first." (check before every full render)
- "No emojis on screen." (clean type looks more premium)
